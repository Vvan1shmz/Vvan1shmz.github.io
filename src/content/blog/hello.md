this is the first post.

i wanted a quiet place: no feed, no counts, only things i actually want to keep. the layout takes after sites like [nathanchen.me](https://nathanchen.me) — a lot of whitespace, almost only text. it is a static site built with [astro](https://astro.build), so anyone with the link can open it.

later this will probably hold:

- questions i am still turning over
- things i read, built, or want to remember
- occasional notes from ordinary days

if you found this page, hello. write if you want.
